Advanced studio output · Blender Cycles

Export a self-contained GLB render job for the local Cycles renderer. Full-scene path tracing adds setting reflections, contact shadows and multi-bounce light transport. This is a local workflow, not a cloud rendering service.

Run from the repository with Blender 4.2+ installed:

blender --background --factory-startup --python-exit-code 1 --python scripts/render_jewellery.py -- design.glb --output renders/design

Produces a PNG, linear EXR, editable Blender scene and provenance manifest. Three-band dispersion is an approximation, not full spectral simulation. Render time depends on hardware and quality settings.
