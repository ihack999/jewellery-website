# Legacy v1 pages (not published)

These are the hand-written HTML pages from the first version of the site. They are
kept for reference only — the live site is now generated from `/store` by
`npm run build` into `/dist`. Old URLs (e.g. `/shop.html`, `/customs.html`,
`/rings/`) redirect to their new homes via `store/site.json → redirects`.

The shared assets they used (`/assets/…`, including the 3D studio in
`assets/js/designer.js`) still live at the repository root and are used by the
new storefront. The browser test scripts in `/scripts` were written for these
v1 pages.
